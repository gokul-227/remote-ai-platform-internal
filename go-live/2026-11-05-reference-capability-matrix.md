## Evidence vocabulary

- **Existing:** implementation is visible in the current source. This alone does not establish deployed behavior or a completed acceptance journey.
- **This change:** added or repaired in the local branch; final integrated tests and release provenance belong to the coordinating agent's test report.
- **Partial:** a bounded implementation exists but one or more requested behaviors or runtime proofs are outstanding.
- **Missing:** the specific behavior was not found in the inspected implementation; this is a scoped source finding, not a proof about every possible branch.
- **Blocked / deferred:** live-provider access, permission, infrastructure feasibility, or the explicit zero-cost/product boundary prevents a completion claim.
- **Observed interface:** an actual REA observation succeeded. Navigation/accessibility evidence does not prove all menus, paid features, permissions, or create/edit/error workflows were exercised.
- **Documented reference:** public vendor documentation cited in [the product audit](2026-11-05-product-audit.md); it is separate from directly observed runtime behavior.
